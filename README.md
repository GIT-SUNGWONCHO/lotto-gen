# 로또 번호 연구소

로또 6/45 번호 추천 앱. 1회차부터 최신 회차까지의 당첨 데이터로 번호별 출현 통계를 내고,
"덜 나온 번호"를 우선해 게임을 만듭니다. 그리고 그 전략이 실제로 효과가 있는지 **같은 화면 안에서 검증해서 보여 줍니다.**

## 실행

```bash
npm start      # http://localhost:4545
npm run update # 최신 회차까지 data/draws.json 갱신
npm run backtest # 전략이 무작위보다 나은지 터미널에서 확인
npm test       # 확률·통계 계산 검증
```

의존성 없음 (Node 18+). 브라우저에서 동행복권을 직접 부를 수 없어(CORS) 서버가 대신 받아 `data/draws.json`에 캐시합니다.

## 데이터로 확인한 것

1,241회차 전체를 분석한 결과입니다.

| 질문 | 답 |
| --- | --- |
| 번호별 출현 횟수가 고른가 | 고르다. χ² = 33.5 (자유도 44), **p = 0.87** — 차이는 전부 우연 범위 |
| 가장 적게 나온 번호 | 9번 (136회, 기대 165.5회, −2.5σ) |
| 가장 많이 나온 번호 | 34번 (186회, +1.7σ) |
| "안 나온 번호"가 다음에 잘 나오나 | 아니다. 1,141개 회차 백테스트에서 평균 적중 0.803개 — 무작위 0.800개와 같음 (z = +0.14) |
| 다른 전략은 | 많이 나온 번호, 최근 30·100회 기준, 미출현 기간, 비인기 번호 모두 z가 ±1 안 |
| 1등 확률을 올리는 방법이 있나 | **없다.** 모든 조합이 1 / 8,145,060 |

바꿀 수 있는 것은 확률이 아니라 **당첨됐을 때 받는 금액**과 **결과의 분포**뿐입니다.

- **남들이 안 고르는 조합**: 당첨 조합을 인기도로 5구간으로 나눠 보면 가장 비인기 구간의 1등 당첨자가 기대의 ×0.92, 가장 인기 구간은 ×1.13. 같은 1등이라도 나눠 갖는 사람이 약 19% 적습니다. 회차별 4·5등 당첨자 수를 당첨번호 45개에 릿지 회귀해 번호별 인기도를 추정합니다.
- **여러 게임이면 번호를 겹치지 않게**: 5게임의 1등 확률은 어떻게 사든 5 / 8,145,060이지만, '적어도 한 장이 5등 이상'일 확률은 같은 번호 5장 2.38% vs 퍼뜨린 5장 11.4%로 달라집니다. 8,145,060개 조합을 전부 세어 정확히 계산합니다.

## 전략

| 전략 | 내용 |
| --- | --- |
| **안 나온 번호** (기본) | z = (출현 − 기대) ÷ 표준편차, 가중치 = e<sup>−강도 × z</sup>. 출현 횟수가 같으면 비인기 번호를 먼저 — 인기도 점수 폭을 출현 1회 차이보다 작게 눌러 더하므로 덜 나온 번호를 앞지르지 못합니다. |
| **1등 집중** | 가장 덜 나온 번호 N개만 후보로 두고 그 안에서만 조합을 만듭니다. 겹침 제한을 풀어 후보에 몰아 줍니다. |
| **비인기 번호** | 인기도 계수가 낮은 번호 위주 |
| **완전 무작위** | 모든 번호를 같은 확률로 |

패턴 필터로 역대 1등 조합, 3연속, 생일 조합(모두 31 이하), 용지 일직선, 등차수열, 같은 끝수를 뺄 수 있습니다.

### '1등 집중'은 확률을 올리지 않습니다

후보 8개(5게임 기준)로 계산하면 이렇습니다.

| | 값 |
| --- | --- |
| 후보로 만들 수 있는 조합 | 28가지 |
| 당첨번호 6개가 모두 후보 안에 들 확률 | 1 / 290,895 |
| 그때 내 5게임에 정답이 있을 확률 | 5 / 28 (17.9%) |
| 1등 확률 | **5 / 8,145,060** — 무작위와 동일 |

후보를 좁힐수록 앞의 확률은 낮아지고 뒤의 확률은 높아져 곱은 항상 같습니다.
바뀌는 것은 결과의 모양입니다. 번호가 겹치므로 5등 이상이 하나라도 나올 확률은 **낮아지고**(퍼뜨린 5장 11.4% → 후보 8개 약 5%),
대신 후보가 맞아떨어지는 회차에는 여러 장이 한꺼번에 당첨됩니다. 확률을 사는 게 아니라 **적게 자주 맞기와 크게 드물게 맞기 중에 고르는** 것입니다.

## 구조

```
server.mjs           정적 파일 + /api/draws, /api/update
lib/dhlottery.mjs    회차 데이터 수집·캐시
public/core/lotto.js 통계·생성·백테스트 순수 함수 (브라우저·Node 공용)
public/app.js        화면
public/charts.js     의존성 없는 SVG 차트
test/lotto.test.js   확률·통계 검증 17종
```

## 알아 둘 것

로또의 기대 환급률은 약 50%입니다. 1,000원어치를 사면 평균 500원이 돌아오고, 어떤 전략도 이 사실을 바꾸지 못합니다.
이 앱은 재미와 통계 학습용이며 당첨을 보장하지 않습니다.
